제안하신 **'거실 사이즈 입력 기반 ANC 자동 설계 및 BOM 산출 프로그램'**은 현장 엔지니어의 실수를 줄이고 프로젝트 관리 효율을 극대화할 수 있는 핵심 도구입니다.

PM 및 PO의 관점에서 이 프로그램을 구현하기 위한 **시스템 아키텍처 및 단계별 개발 로드맵**을 다음과 같이 제안합니다.

---

### 1. 프로그램 핵심 아키텍처 (System Architecture)

프로그램은 현장 휴대성을 고려하여 **Web-based Responsive App** (반응형 웹 앱)으로 개발하는 것을 권장합니다. 태블릿이나 스마트폰에서 즉시 조작하고 결과를 서버에 동기화하기 위함입니다.

* **Frontend**: React.js 또는 Vue.js (Canvas API 혹은 SVG를 이용한 도면 시각화)
* **Backend**: Node.js 또는 Python (FastAPI) - 설계 로직 처리 및 PDF 생성
* **Database**: PostgreSQL 또는 Firebase (20세대의 실사 데이터 및 설계 이력 관리)

---

### 2. 주요 기능별 구현 로직 (Core Logic)

#### 가. 자동 배치 알고리즘 (Auto-Layout Engine)

거실의  값을 입력받아 좌표를 생성합니다.

* **Vibration Sensor (VS)**:
* 9개 포인트를  격자 형태로 배치합니다.
* 좌표 산출 예: , 


* **Speaker (SPK)**:
* 우물천장 라인(Edge)을 따라 10~12개를 배치합니다.
* 입력된 사이즈에 따라 장변과 단변에 배치될 개수를 비율에 맞춰 자동 할당합니다.


* **간섭 회피 (Collision Avoidance)**:
* UI 상에서 에어컨이나 조명 위치를 '드래그'하거나 좌표로 입력하면, 해당 지점의 센서/스피커를 인접한 안전 구역으로 자동 이동(Re-positioning)시키는 로직을 포함합니다.



#### 나. 지능형 BOM 산출 모듈 (Smart BOM Generator)

배치된 좌표를 기반으로 자재 수량과 케이블 길이를 실시간 계산합니다.

* **하드웨어 수량**: 배치된 스피커 및 센서 노드 수 자동 카운트.
* **케이블 길이 계산**:
* 각 노드 간의 맨해튼 거리(Manhattan distance) 또는 최단 경로 알고리즘을 적용하여 필요한 **A2B 케이블(Harness)**의 총 연장 및 규격별(1.2m, 7.0m 등) 수량을 산출합니다.

            
* **고정 자재**: 제어기(1개), 어댑터(1개), SD카드 등 세대당 공통 자재 자동 합산.

#### 다. PDF 자동 리포트 생성 (Auto-Documentation)

* **Shop 도면**: Canvas/SVG 데이터를 PDF용 벡터 그래픽으로 변환.
* **실사 데이터 연동**: `1. 세대별 사전 실사 대장`의 체크리스트 결과와 설계 도면을 하나의 문서로 병합하여 출력합니다.

### 3. 사용자 경험(UX) 및 인터페이스 설계

현장의 열악한 환경에서도 오입력을 방지하기 위한 UX 전략입니다.

1. **Step-by-Step 입력**: [세대 정보] → [실측 사이즈 입력] → [장애물 마킹] → [설계 확인] 순서의 위저드 방식.
2. **도면 인터랙션**: 자동 배치된 센서를 손가락으로 미세 조정할 수 있는 드래그 인터페이스.
3. **현장 사진 연동**: 스마트폰 카메라로 촬영한 천장 사진을 도면 뒤에 레이어로 깔아 실제 간섭 여부를 시각적으로 대조(Overlay).
